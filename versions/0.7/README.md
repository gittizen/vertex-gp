# 0.7 — KlecMania *(současná)*

**Oproti 0.6:** rebrand na **KlecMania** (logo skate pink/cyan beze změny) + Space drift brzda, mute, bike boost, Tarantino Klecany.

## Hrát
- Netlify (produkce): https://klecmania.netlify.app/
- GitHub Pages archiv: https://gittizen.github.io/vertex-gp/0.7/

## Co je nového
- Název **KlecMania** v UI / title / docs — logo KCLC **stejné** (růžová K/L, cyan C)
- **Space** = e-brake / drift brzda (default zapnuto) u aut, moto, formule…
- Skate a kolo **nemají** drift brzdu (šlapání / odrážka / triky)
- Sticky boost (Alt/Tab); kolo +~30 % šlapání; čitelnější AI board animace
- Mute toggle jako CZ/EN; Klecany Tarantino 60:30:10 (Volvo beze změny)
- Náhodné jméno hráče (localStorage) místo defaultu Filip — žebříček / lobby
- Mobil: FS pady, pauza, větší Plácek; oddělený scroll v tuningu
